# Content changelog

Every change made to page copy in this repo, newest first. One line per change.

This is read at launch and monthly by ZilvaEdge's `/content-reconcile`, which compares it against
what the site actually says. A change it can prove happened but cannot find explained here is
reported as needing attention, so an unlogged edit becomes somebody's question later. Logging it
takes ten seconds.

## What to log

- Any edit to a file in `content/`
- Microcopy written straight into Breakdance: CTAs, button labels, short connective copy
- A page added, removed or renamed

## What not to log

- Layout, styling, spacing and image work that leaves the words alone
- Copy that arrived through ZilvaEdge's `/content-release`. That is already in `git log` with the
  Doc it came from

## Format

```
| Date | Page | What changed | Why | Who |
```

Keep "what changed" concrete. "Reworded hero" tells a reader nothing six weeks later.
