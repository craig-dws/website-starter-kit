# Active sessions (claim board)

Each session working on this build claims its work here before starting, and releases it when
done. **Read this before you start.** Do not take work another session has claimed, and do not
write global settings or shared files while another session is active. See
`.claude/reference/parallel-builds.md`.

| Session | Working on | Object / scope | Claimed | Status |
|---------|-----------|----------------|---------|--------|
| _(example)_ | Footer | post 340 | 2026-07-26 14:00 | done |

Release: set Status to `done` (or delete the row) when finished. A claim older than ~2h is
probably a crashed session, confirm before overriding it.
