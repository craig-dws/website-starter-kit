# Client Website Build

**Start with [START-HERE.md](START-HERE.md).** It is the front door: what this repo is,
how to run the build (guided or advanced), how to connect the site, and troubleshooting.

One client build, scaffolded from the AI Web Design System. Staging only. One repo per
client, never shared.

**This folder is the reusable starter kit (version-controlled).** To start a new client build,
copy it to a new location **excluding the `.git` directory**, then `git init` there so the
client build gets its own clean history.
